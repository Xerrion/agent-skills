# Primitive colors

Exact definitions: [color.json](../tokens/color.json).

The palette contains 95 primitive tokens.
Names combine a hue and a step, such as `blue.500`, `neutral.200`, and `red.500`.
`midnight` and `white` are standalone tokens.
Eight-digit hexadecimal values use the final two digits for alpha.
