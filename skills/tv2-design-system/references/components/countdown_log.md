## 1.0.0
**7.11.2025**

- Størrelsen på countdown er statisk på samme måde som vores buttons
- Countdown kommer nu i to størrelse (samt en unik størrelse til TV) som er afstemt med højden på vores buttons;
- Default countdown → Default button
- Small countdown → Small countdown
- Vi anvender “light” fontvægt for både tal og tekst for at skabe en visuel sammenhæng mellem elementerne.
