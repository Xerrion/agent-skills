## Appearance

Preview shows a label above a single wide outlined field. The label and field share a left edge. The selected value sits inside the field toward the left, with horizontal inset from the border. A light downward chevron sits near the right edge, separated from the value by open space. Value and chevron are vertically centered within the field.

The field has a muted light outline, navy interior, and apparently square corners. The value is prominent and uses light text. The preview shows no helper text or error line below the label or control.

## Recorded rules

The component was introduced with the new input design. Tooltip size is 16. The preview supplies the closed select with a chosen value. The local record does not define the expanded menu's surface, option spacing, selected option marker, or keyboard focus appearance.
