## Appearance

Preview shows a dark quotation-mark glyph centered inside a pale peach circular surface. It has no visible text label or contrasting outline. The filled circle supplies the visual emphasis behind the glyph.

## Recorded rules

The original Default and Transparent variants follow light/dark logic. Icon version 1.1.0 deprecates Icon Marker and moves its colored circular background into Icon. Use Icon for new work. The replacement is documented in [Icon](icon.md) and the [Icon design record](icon_log.md). The Marker log's 1.1.0 entry repeats Icon Button X-Small and Primary color changes; it does not establish those values as Marker dimensions or colors.
