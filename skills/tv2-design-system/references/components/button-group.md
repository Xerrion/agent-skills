## Appearance

Preview shows separate pill buttons arranged in one horizontal row with visible space between them. Each label is centered inside its own pill. The first option, "Sæson 1", has a white surface with dark text. The next option has a muted dark surface with white text, so the leading option is visually emphasized. A third pill is partially visible at the right edge. The pills have no shared enclosing track.

## Recorded rules

Version 1.3.0 changes the size from 34 px to 32 px and turns the recorded `Trading icon` property off by default. The individual element is named Button Group Controller. Figma supports ten controllers, with controllers 6 to 10 hidden by default. This is a Figma default, not a rule limiting the runtime group to five choices.
