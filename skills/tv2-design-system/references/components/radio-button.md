## Appearance

Preview shows a vertical group with a bold group heading and a smaller description directly below it. Five choices sit below that introduction. Each row has a circular control on the left and a text label on the right. The circles form one vertical column and the labels share a second left edge. All rows use the same control placement and text alignment.

Four choices show a thin light circular outline around a navy interior. The selected choice shows a white filled circle with a smaller dark circular center. This makes selection visible through the control's interior as well as its outline. The example contains no enclosing card, helper text below individual choices, or visible error message.
