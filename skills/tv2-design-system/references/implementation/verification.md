# Implementation verification

1. Confirm that copied fonts, artwork, and stylesheets load from their application URLs.
2. Compare rendered colors and typography with the selected token values in both themes.
3. Check the web layout below and above 680 px and 1024 px; check television styles separately when relevant.
4. Use the keyboard and check focus, link labels, contrast, and relevant component states.
5. For email, verify destination URLs and preview the final inline HTML in the intended mail clients.
