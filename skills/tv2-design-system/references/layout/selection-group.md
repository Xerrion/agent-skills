# Selection group composition

Radio choices form a vertical stack with a narrow control column and a separate text column. A group heading and description appear above the choices. The checked Checkbox example uses the same control/text separation with supporting copy under its label.

Evidence: [Radio preview](../../assets/components/radio-button.png), [Checkbox preview](../../assets/components/checkbox.png), [Radio Button](../components/radio-button.md), [Checkbox](../components/checkbox.md).
