# Feedback panel composition

Section Notice and Validation Summary place a status icon in a leading column and text in a wider column. Wrapped text follows the text column's left edge. System Banner also reserves a separate trailing area for its close control.

Evidence: [Section Notice preview](../../assets/components/section-notice.png), [Validation Summary preview](../../assets/components/validation-summary.png), [Section Notice](../components/section-notice.md), [Validation Summary](../components/validation-summary.md), [System Banner](../components/system-banner.md).

This describes the pictured arrangement. Use the component's pinned measurements and current variant rules for exact dimensions.
