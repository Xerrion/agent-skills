# GlideElement: server scoped contracts

API references: [global API](../../sources/api-reference/server-api-reference/glide-element-global.md) and [scoped API](../../sources/api-reference/server-api-reference/glide-element-scoped.md).

For other scoped methods, use the scoped API reference above.
Examples: [task guide](../../glide-element.md).

The scoped API documents `getReferenceTable()` and `setPhoneNumber()`.
It also documents `getGlobalDisplayValue()` for international phone formatting.
Those methods have field-type-specific purposes.

The scoped API includes `getDecryptedValue()` for two-way-encrypted password fields.
Its presence is not permission to retrieve, log, or expose credentials.
