# Udgivelsesnoter for Humanizer på dansk

## 1.0.0

- Første selvstændige danske udgave med navnet `humanizer-da` og filen `SKILL.md`.
- Dansk vejledning, danske eksempler og 26 mønstre i seks grupper.
- Regler for dansk ordbygning, bindestreger, passiv, komma og anførselstegn.
- Bevar oplysninger, kildegrundlag, usikkerhed og skribentens stemme. Tilføj ikke opdigtede fakta eller personlige oplevelser.
- Bevar selvstændige forbehold som »måske« og »muligvis«, også sammen med »kan« eller en forventning.
- Returnér som standard kun omskrivningen. Vis kun udkast og kritik på anmodning.
- Separat installation ved siden af den engelske skill.
- Hele udgaven ligger i én selvstændig mappe med `SKILL.md`, `README.md`, `CHANGELOG.md` og `LICENSE`. Mappen kan kopieres samlet uden filer fra den engelske udgave.
